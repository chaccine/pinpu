在当前目录创建一个「音乐频谱可视化」纯静态网页项目(index.html + style.css + app.js，可拆更多文件，不要构建步骤，不依赖外部CDN)，界面全部中文，手机和电脑都能用。要求：
1. 输入：本地音频文件(文件选择按钮+拖拽到页面)；麦克风输入按钮；内置「演示曲目」按钮：用 Web Audio 振荡器+噪声合成一段测试曲(底鼓four-on-the-floor节拍约120BPM + 低音线 + 旋律 + 踩镲噪声)，循环播放，无需任何文件。播放/暂停按钮、可拖动进度条(文件模式)。
2. 用 Web Audio API 的 AnalyserNode 分析，Canvas 2D 绘制。包含 3 种可切换视觉模式：(a)环形频谱：中心圆周围放射状柱条，平滑过渡；(b)镜像柱状波形：上下对称的柱条+波形线；(c)粒子星系：粒子随音乐旋转扩散。
3. 节拍检测：在低频段做简单能量检测(当前能量 > 滑动平均*阈值 且有最小间隔)，检测到节拍时触发粒子爆发、整体色相偏移(调色板随节拍变化)、中心圆缩放脉冲。
4. 发光效果(shadowBlur 或 lighter 混合模式)，柱条平滑(指数平滑)，目标60fps，用 requestAnimationFrame，画布随窗口大小和 devicePixelRatio 响应式缩放，注意移动端性能(限制粒子数量)。
5. 全屏按钮(Fullscreen API)，模式切换按钮，界面控件半透明、移动端触控友好，播放时几秒无操作可自动淡出控件。
6. 暴露 window.__pinpu = { mode, beats, playing, setMode(i) } 之类的调试对象，便于自动化测试读取节拍计数和当前模式。
